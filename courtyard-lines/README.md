# 廊间 · Courtyard Lines

基于用户确认的新户型图重建的三室两厅两卫住宅展示。旧模型坐标、墙体和家具布局已替换；网页品牌、交互、原生 Three.js 技术栈和现有 GitHub Pages 发布方式保留。

## 空间依据与边界

唯一平面依据为本轮提供的 1312 × 1199 像素户型图。北向对应 -Z，图像像素以 0.015 米/像素统一转换；原图部分尺寸标注与分段尺寸不自洽，因此这是比例展示，不是测绘、施工或无障碍认证。“约 145㎡级”是住宅定位，不代表计算出的套内面积。

- 西侧入户、完整玄关；西北厨房与独立家政，向南连接连续客餐厅和景观阳台。
- 中部私区走廊连接公卫、书房与南向次卧；东侧主卧保留睡眠、衣帽、主卫套房关系。
- 墙体及门板采用约 1.25m 剖切表达，窗框与柜体保留高度层次；房间视角只改变相机与目标点。
- 家具用于校验通行：东向沙发面对电视、六人餐桌、冰箱→水槽→备餐→灶台→出菜、独立洗烘与清洁收纳。
- 次卧采用约 1.90 × 1.35m 床体，床尾约 0.60m，床侧约 0.63–0.66m；衣柜按移门使用。空间紧凑，不额外塞入书桌；工作与留宿由书房承担。

## 本地预览与检查

在仓库根目录使用已安装的静态服务器，例如：

```sh
python -m http.server 4173
```

打开 `http://127.0.0.1:4173/courtyard-lines/`。直接双击 HTML 不适用于 ES Module。

- `?stage=structure&view=plan`：仅建筑、俯视检查。
- `?view=plan`：带家具俯视检查。
- 默认页面：七个相机预设、旋转、缩放、重置、即时日夜切换，以及厨房水龙头、客厅主灯、书房台灯、客厅窗帘和电视互动。

在本目录执行：

```sh
node scripts/verify-layout.mjs
node scripts/verify-render-loop.mjs
node --check src/main.js
```

几何检查覆盖登记家具与墙体、五扇门的扫掠、六处门洞及两侧房间连接、五条预留路线与家具/墙体/打开门扇、六把餐椅拉出位置、床体、双卫、独立家政及沙发/电视关系。它不是任意旋转、所有装饰几何或实际施工的完整碰撞证明。渲染调度检查使用模拟 DOM/renderer 运行实际 main.js，检查静止休眠、阻尼、短时动画、日夜切换、尺寸变化与页面隐藏/恢复；不代替 WebGL 和真机帧率测试。还需在浏览器检查桌面、390px、房间镜头、日夜、资源加载与 WebGL。

## 代码结构

- `src/architecture.js`：新图坐标、建筑外轮廓、地面、墙、门窗及功能分区。
- `src/furniture.js`：核心家具、设备及可检查的占地范围。
- `src/materials.js`：低饱和材质，程序化木板、湿区砖缝与织物。
- `src/main.js`：灯光、相机自适应取景、OrbitControls、互动状态协调、UI 和按需渲染。
- `src/interaction.js`：注册式射线交互、拖拽误触阈值、桌面/触控命中与短时动画。
- `styles.css` / `index.html`：现有作品集视觉及响应式界面。
- `vendor/`：本地 Three.js 与 OrbitControls，无运行时 CDN。
- `scripts/verify-layout.mjs`：无第三方测试依赖的几何验收。

## 视觉与性能

木地板、墙体、湿区、木柜与织物使用不同明度和色相。夜间由少量暖光照亮主要生活区，不以单纯降低曝光模拟关灯。日夜一次性切换，不做多灯逐帧渐变。

DPR 上限 1.5；一盏阴影灯、六盏无阴影暖光及一盏日间补光；复用基础几何与材质，静止时停止动画帧回调和 WebGL 绘制。水流与窗帘仅在短时切换动画期间请求连续重绘，窗帘移动时刷新缓存阴影。页面隐藏时取消待绘帧，返回时恢复。手机为模型、44px 工具按钮和状态文字预留独立区域，房间导航可横向滚动。
